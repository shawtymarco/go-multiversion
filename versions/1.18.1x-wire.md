# Minecraft 1.18.1x wire audit

Target: stable 1.18.10, 1.18.11, and 1.18.12, protocol 486.

## Locked wire source

- Introduction: Sandertv/gophertunnel `faf9bceadcb30cf431e4c8111ad3b877c7b521a3`.
- Final protocol-486 snapshot: `2cb1e399e53928529916dd2bda1efd11a0ac374d`.
- Native snapshot: `7f058e5ddc393eaa0480dae338c5eee2feb323e6`, protocol 2169.

The decoder also accepts the later message-only Text type 11 as a narrow
compatibility extension. This lets injected client display hotkeys reach the
server's non-chat ignore policy instead of turning an otherwise valid packet
into a connection-closing unknown-enum panic.
- Historical packet pool ceiling: ID 178 (`CodeBuilderSource`).
- Historical/current ID anomaly: `MapCreateLockedCopy` and `OnScreenTextureAnimation` are swapped at IDs 130/131.

## Transport boundary

Protocol 486 uses RakNet v10, sends `Login` before `RequestNetworkSettings`, and enables flate compression
immediately. A legacy compressed batch is `0xfe | flate(batch)` and has no modern compression-algorithm byte.

gophertunnel keeps the current go-raknet dependency and adds a narrow v10 handshake adapter:

- incoming v10 `OpenConnectionRequest1` is admitted through the wire-compatible current RakNet path;
- the negotiated v10 value is retained on the accepted connection;
- only v10 connections take Login-first and legacy-compression paths;
- native v11 and RequestNetworkSettings behaviour remains unchanged;
- `raknet-v10` exists only for development/oracle dialers.

The Tedac RakNet/gophertunnel forks were inspected as a checklist. They were not pinned because their 2025
RakNet base regressed the current 2026 native listener. No GPL code from didntpot/multiversion was copied.

## Packet implementation

The protocol-486 adapter composes current-to-975 primitive/shared codec work where byte-identical, then owns
every additional protocol-486 delta. Gameplay and registry conversion remains direct between 486 and native.

Covered high-risk areas include:

- StartGame embedded item registry and synthetic internal ItemRegistry for current dialers;
- old packet pool pruning plus seven target-only packet constructors;
- player input, inventory transactions, stack requests/responses, and container-ID insertion mapping;
- numeric recipe ingredients and pre-smithing CraftingData;
- legacy AdventureSettings and AddPlayer abilities;
- entity metadata type table and two-word flag insertion mapping;
- player skins/persona fields and player-list action splitting;
- resource-pack negotiation, text/forms, commands, maps, structures, sounds, and volume entities;
- LevelChunk request sentinels, signed sub-chunk offsets, height maps, and blob-presence rules.

## Oracles

- 170 zero-value packets generated by the exact historical pool are byte-compared with the adapter.
- The one historical zero-value writer panic (`ClientBoundMapItemData`) is covered with a populated fixture.
- 30 populated high-risk fixtures, including StartGame, CraftingData, commands, map pixels, skins, chunks,
  inventory, entities, resource packs, and sound events, pass exact historical bytes in both directions.
- Packet conversion tests verify the native input is not semantically chained through protocol 975.

## Known scope

- Stable protocol-486 listener support is implemented for 1.18.10-1.18.12.
- Preview builds, protocol 475, and protocol 503 are separate release trains.
- Automated dialer validation uses the explicit `raknet-v10` development network. Normal native dialers remain v11.
