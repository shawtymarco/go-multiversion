# Minecraft 1.26.60 native integration

The stable native protocol is 2225. The same ID was used by Preview 1.26.60.30,
but the final Animate packet has a required uint8 Hand instead of an Optional.
The outgoing 2193 codec drops the field and restores the main-hand default.

- Native upstream wire: Sandertv/gophertunnel `d4836105abdc5de0496cf62b69413a591af5f8fb` (1.26.60 support plus the PR 545 StructureBlockUpdate, PlayerVideoCapture and camera spline layout fixes).
- Native fork (no longer pinned; the root module uses upstream gophertunnel master `0e179fc4bb08`): shawtymarco/gophertunnel `e731813db0edd43af7d882c9190cb85b2934509f`.
- Stable data: df-mc/dragonfly PR 1481, `d86aefd9ff9b6a357d6dfadab2093af811545256`.
- Outgoing 2193 wire: `9e7f28092180fd2cae6c2a0ebc32f1c8882d26f1`.
- Outgoing 2193 data: `data/v2193/manifest.json`.

`data/v2225/manifest.json` records each exact Git blob, SHA256 and encoding.
The stable snapshot contains 23,960 typed block states and 2,080 items. The
Preview packages remain separate, immutable provenance records. Runtime callers
supply the finalized actual block/item registries; tests use stable snapshots.

Native Dragonfly connections map local block indexes to full state hashes before
chunk-cache hashing, and translate item/block/event payloads through NativeProtocol.
Older clients retain their direct target palette encodings. Native and historical
packets must never be translated twice across the private Spectrum backend stream.

The consumer must wire both public transports and select the same finalized
catalogue on proxy and backend. Login-first legacy clients retain RakNet; current
clients use NetherNet. Transport configuration, persistent identity and exposed
TCP/ICE ports belong to the consumer, not a historical adapter.

Validation uses every historical adapter, frozen 2193 wire oracles, stable data
integrity, gameplay effects with reordered native IDs, and consumer transfer/cache
regressions. Automated evidence does not replace native client visual validation.
