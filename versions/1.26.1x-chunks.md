# Minecraft 1.26.1x chunk mapping

Protocol 944 implements Dragonfly's generic `BlockRuntimeIDMapper` through
the same pre-hash integration used by protocols 975, 844, and 827. Each native
palette runtime ID is resolved to identifier plus complete typed properties,
then mapped directly to the protocol-944 registry before chunk bytes and cache
hashes are produced.

The 1.26.1x family retains the modern world height, sub-chunk, and 3D biome
palette model used by the later 1.26 families. No protocol-944-specific raw
chunk packet layout was identified between the locked target and native
baseline. Block palette mapping remains version-specific because its registry
contains 15,846 states and target air is runtime ID 12531.

LevelChunk cache-off/cache-on, SubChunk, cache hashes, block updates, falling
block metadata, inventory block runtime IDs, and fallback-induced palette
deduplication therefore use the existing tested generic path. The adapter does
not mutate the live world chunk and does not convert payload bytes after cache
hashing.

Automated integration verifies that the configured adapter exposes the
pre-hash mapper and that common/native-only states map to exact target IDs or
the documented target-air fallback. A real 1.26.1x Mojang client must still
visually confirm representative chunks before the family is described as
fully validated.
