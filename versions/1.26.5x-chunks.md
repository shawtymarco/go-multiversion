# Minecraft 1.26.50 Preview chunk preparation

Protocol 2192 changes `SubChunkEntry` height-map and render-height-map payloads from 256 to 272 signed bytes.
The protocol-2169 adapter retains the exact 256-byte layout and has a historical byte oracle covering the
changed packet.

Block palettes use Dragonfly's existing protocol capability before encoding, hashing, and cache insertion:

```text
protocol-2192 world RID
-> semantic native block state
-> protocol-2169 state with corner/connection compatibility
-> protocol-2169 RID or explicit air fallback
-> encoded target chunk/cache blob
```

The adapter exposes `MapBlockRuntimeID` only after its registry-aware constructor succeeds. A Preview 26
Castle integration check validated every historical adapter against the new native registry and separately
validated the protocol-2169 block/item snapshots. Runtime deployment and visual client validation remain
deferred until stable 1.26.50.
