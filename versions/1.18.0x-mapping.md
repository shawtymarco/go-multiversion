# Minecraft 1.18.0x mapping audit

The target contains 7,948 block states, 1,081 items, 1,386 creative entries, and 3,307 legacy-state mappings. Direct native mapping records 9,621 block fallbacks, 934 native-only item fallbacks, and 11 target-only items. The target air runtime ID is 134 and target block order is preserved exactly.

The BedWars Dream Defender is a deliberate exception to the default native-only item policy. Current
`minecraft:iron_golem_spawn_egg` stacks are encoded as the target's `minecraft:spawn_egg` with metadata 20,
and that exact target variant maps back to the current identifier. The metadata is anchored by Mojang's item
upgrade schema (also consumed by PocketMine-MP), which introduced the flattened Iron Golem egg from legacy
spawn-egg metadata 20. Stack count, network identity, custom name, lore, and NBT are preserved.
