# Minecraft 1.26.1x registry mapping

Protocol 944 is enabled only through `ProtocolsWithRegistries`. It loads the
exact Dragonfly `16359459d62a440c36c077c90705127107d9dead` block, item,
creative, crafting, furnace, and potion snapshots and maps them directly
against the native 1.26.45 registries.

The target block registry uses Dragonfly's stable FNV-1 identifier sort while
preserving source order for states with the same identifier. Verified target
anchors are:

| State | Target runtime ID |
| --- | ---: |
| `minecraft:stone` | 2533 |
| `minecraft:grass_block` | 11063 |
| `minecraft:air` | 12531 |
| `minecraft:bedrock` | 13080 |
| `minecraft:oak_planks` | 14389 |

Every target state resolves to a native semantic state. Of 17,499 native
states, 1,653 states absent from protocol 944 use the explicit target-air
fallback. Of 1,976 native items, 142 are absent and are hidden clientbound.
The historical registry has 1,907 items. Its one target-only item,
`editor:map_marker_spawn_egg` at runtime ID 843, remains advertised for exact
registry fidelity but is rejected serverbound because native has no semantic
equivalent.

Creative conversion starts from the native packet, maps each surviving item
and block, and preserves `CreativeItemNetworkID`; unsupported entries are
filtered. The focused test selects a surviving creative entry and proves the
same selection ID returns serverbound. Current recipes are mapped and filtered
semantically. Protocol 944 additionally receives the exact 263 historical
furnace recipes removed from later packet models.

`data/v944/fallbacks.json` records every fallback deterministically. The
report is generated against native Dragonfly
`ba86ce9567d9fe5936201bf6a951a5a133bd8b2a` and target Dragonfly
`16359459d62a440c36c077c90705127107d9dead`.
