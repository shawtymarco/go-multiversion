# Minecraft 1.26.1x wire audit

## Scope and authority

This audit covers stable Minecraft 1.26.10 through 1.26.14 under protocol
944. The executable target is gophertunnel `165bd86be6cde0c3300e4c22a3c6daa45d290524`
(`v1.55.2`), and the native model is
`7f058e5ddc393eaa0480dae338c5eee2feb323e6` (1.26.45/protocol 2169).
Endstone protocol docs `c85eea649cc59b3339fecca1e87ecd3ad0110da1`
identify 1.26.14.1 as network version 944. No stable patch-internal wire
branch was found, so 1.26.14 is the canonical family version.

Protocol 944 uses the same RakNet v11, `RequestNetworkSettings`-first,
negotiated compression, encryption, and batch framing path as the native
listener. It needs no transport hook.

## Implemented differences

- The pool removes post-944 packets and restores the protocol-944
  `DebugDrawer` layout at the packet ID later reused by `PrimitiveShapes`.
- Biome surface data is written in the direct pre-builder layout. Protocol-975
  surface/subsurface builders and noise-gradient data are not emitted.
- `InventorySlot` and `MobEquipment` use the pre-975 item-instance layout;
  dimension entries omit `DimensionType`.
- Actor and level-sound events omit `FireAtPosition`; play-sound handles,
  movement friction/bounce/drag fields, extended diagnostics, profanity
  options, new move flags, graphics parameters, actor events, sounds, and
  disconnect reasons are filtered or downgraded without mutating input.
- Attribute layer settings use the protocol-944 tagged weight representation.
  Current float weights use tag 0; target string weights decode safely without
  inventing a current semantic field.
- Data-store change/control types use fixed uint32 widths on both clientbound
  and serverbound packets. Enchantment cost uses varuint32.
- Locator waypoints use the old optional numeric texture ID. Current path/size
  textures have no verified reverse mapping, so their update bit is cleared.
- Gathering join information restores the two UUID fields used by protocol
  944. The current scenario string has no equivalent and is omitted.
- Available-command float IDs are already identical between protocol 944 and
  native, so the protocol-975 float remap is deliberately not applied.
- Entity metadata keys and flags introduced after protocol 944 are omitted at
  the adapter boundary.

## Verification

`V944_WIRE_ORACLE` points to a helper built from exact historical
gophertunnel `165bd86b`. It decodes and byte-identically re-encodes all
populated high-risk fixtures and every encodable constructor in both packet
pools. The configured 263-entry furnace payload also round-trips byte-for-byte
through that historical Reader and Writer (8,181 bytes; SHA256
`308fc570a59ca9f927a399faf65b1ab995ddd881c5b1f0b1b68b32e3df68e6af`).
