# Minecraft 1.21.5x chunk audit

Protocol 766 uses version-9 sub-chunk palettes and pre-hash runtime IDs. `MapBlockRuntimeID` maps every palette entry directly from the native registry to the locked target order; native-only states fall back to target air and are listed in `data/v766/fallbacks.json`. Multi-entry SubChunk responses and render height maps use the exact target-era wire layout.
