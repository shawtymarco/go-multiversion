# Minecraft 1.21.130-1.21.132 registry mapping

Protocol 898 loads exact Dragonfly
`8d1311b36535d03c7e79932b7ddaf057922ce1f3` data. Counts and block anchors
match protocol 924, but item, creative, crafting, furnace, potion, and smithing
blob contents are independently hashed. The target-specific smithing snapshot
contains 12 entries and is retained because it differs from native.

Direct semantic mapping resolves all 15,845 target block states and all 1,905
target items. The fallback report records 1,654 native-only block states and
143 native-only items, with target air RID 12530 and no target-only items.

Creative selection handles are preserved from the actual native packet.
Smithing/crafting packets remain based on the current runtime's advertised
recipe IDs so serverbound requests resolve to the same native recipes; the
historical blobs provide exact audit evidence rather than a new sequential-ID
source.
