# Minecraft 1.26.3x wire audit

## Scope and authority

This audit covers stable Minecraft 1.26.30, 1.26.31, 1.26.32, 1.26.33,
1.26.34, and 1.26.36 under protocol 1001. The canonical target is the final
historical gophertunnel protocol-1001 snapshot
`0a2ecd5633ea1466ff97f6d4718df66ec14d054f`; the native model is
`7f058e5ddc393eaa0480dae338c5eee2feb323e6`.

The final Endstone `r26_u3` schema at
`32edc45c9f20591b6529dbbb82de8bc9effba878` was used as an independent
BDS-derived cross-check. The shared protocol ID was not treated as proof of
wire identity by itself. No stable patch-internal wire branch was identified
in the locked sources, so `1.26.36` is the canonical family version.

## Implemented differences

- The packet pools remove `ServerPlayerPostMovePosition` and reject
  client-originating `UpdateBlock`, matching the historical pools.
- Packet-specific layouts cover abilities, commands, creative content,
  dimensions, inventory transactions, item stacks, recipes, maps, movement,
  player input/list/skin data, resource-pack negotiation, scoreboard data,
  diagnostics, `StartGame`, sub-chunks, and the other changed protocol-1001
  packets registered in `protocols/v1_26_30/packet_registry.go`.
- Shared IO restores protocol-1001 entity metadata, item/user-data,
  descriptors, stack requests, transaction data, game rules, ability values,
  and shape-data handling wherever current packets embed those types.
- `PlayerList` and `SetScore` packets containing mixed operations are split
  without modifying the input packet. Unsupported post-1001 sound updates and
  `ServerPlayerPostMovePosition` are dropped because protocol 1001 has no
  faithful representation.
- `StartGame` is shallow-cloned before its family game version is selected, so
  conversion does not mutate the native packet.

Registry blobs, block/item runtime-ID mapping, recipe/creative data mapping,
and chunk palette translation are explicitly outside this step. Protocol 1001
therefore remains absent from the public `Protocols()` catalogue.

## Verification

The focused suite checks packet-pool identity, bidirectional conversion,
input non-mutation, mixed-operation splitting, and populated wire values. With
`V1001_WIRE_ORACLE` pointing to a helper built from historical gophertunnel
`0a2ecd5`, it also checks every valid zero-value packet in both historical
pools and populated high-risk fixtures by exact decode/re-encode equality.
