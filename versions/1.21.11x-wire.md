# Minecraft 1.21.11x wire audit

## Scope and authority

This adapter covers stable Minecraft 1.21.110, 1.21.111, 1.21.112,
1.21.113, and 1.21.114 under protocol 844. Minecraft 1.21.120 starts
protocol 859 and is deliberately excluded. The executable target oracle is
gophertunnel `bf05a1ac6b1da4046890196dc49e15a621dcdbd6`, the last corrected
protocol-844 revision before the 1.21.120 update. The native model is
`7f058e5ddc393eaa0480dae338c5eee2feb323e6` at protocol 2169.

Mojang's `r/21_u11` protocol documentation is pinned at
`dde7580f247ead8734bdb94672654ef9016c946a`. No patch-internal wire split was
found between the locked stable 1.21.11x releases, so one adapter serves the
family and selects only the advertised StartGame version from the five-version
allow-list.

## Implemented differences

- The listener/server pools match the historical 79 client-originating entries
  and 211 server-originating entries, except historical
  `ServerScriptDebugDrawer`. Its ID collides with current `PrimitiveShapes` and
  there is no faithful current representation, so both are excluded at that
  boundary. All post-844 packet IDs are rejected.
- Packet layouts restore protocol-844 resource-pack stack, inventory/item,
  transaction, command, text/event, movement, camera, diagnostics, scoreboard,
  StartGame, structure, block-position, biome, recipe, map, and sub-chunk
  representations.
- Historical unsigned-Y block positions are used everywhere required,
  including sound positions and nested structure/block-change values.
- The 566-entry numeric LevelSoundEvent table is generated from the exact
  historical numeric list and gophertunnel's later numeric-to-string transition.
  Native-only sounds use the historical default event.
- Command permissions, argument types, enum index widths, chained subcommands,
  command origins, and output messages use the protocol-844 representation.
- Old item instances and inventory transactions retain their original NBT and
  stack-network-ID layout. Input packets and slices are not mutated.
- Current-only packet fields are omitted or cleared on upgrade. Unsupported
  packets are dropped explicitly rather than written under a colliding ID.

Registry snapshots, semantic runtime-ID mapping, recipes, and palette mapping
are documented separately. The parameterless `Protocols()` catalogue does not
construct protocol 844 because it has no native registries.

## Verification

The suite validates identity, exact pool sizes, all five allowed GameVersions,
input non-mutation, mixed packet splitting, and populated boundary fixtures.
With `V844_WIRE_ORACLE` pointing to the helper built from historical
gophertunnel `bf05a1a`, every valid zero-value packet in both pools and all
populated/high-risk fixtures decode and byte-identically re-encode. Fixtures
cover negative coordinates, old command enums, all changed inventory forms,
biome chunk-generation data, camera aim assist, event field widths, sound IDs,
creative and crafting data, and cache/status packets.
