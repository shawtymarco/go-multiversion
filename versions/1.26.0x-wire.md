# Minecraft 1.26.0-1.26.3 wire audit

Protocol 924 uses final historical gophertunnel
`9c440d5f78803810c3e82424f1f331895eaea799`; native is protocol 2169 at
`7f058e5ddc393eaa0480dae338c5eee2feb323e6`. All four stable releases use
RakNet v11 and the normal `RequestNetworkSettings` negotiation path.

The adapter restores unsigned-Y block positions across StartGame, inventory
transactions, sounds, structure packets, block updates, map tracking, and
block-change entries. It also restores mandatory graphics values, legacy
camera FOV/spline easing, the old StartGame server-join strings, input-lock
position data, data-driven UI close/show layouts, and the pre-custom-count
VoxelShapes packet. Post-924 data-store, attribute-layer, locator, party,
clock, resource-pack-validation, store, presence, and sound packets are
dropped explicitly.

The protocol-924 packet pool and every populated changed layout decode and
byte-identically re-encode through the exact historical Reader/Writer. The
configured 263-entry furnace payload is 8,181 bytes and round-trips with
SHA256 `99d5901762d56416997ae8a267d7ca42eb6cecb631a14805e0893e282f4c9074`.
