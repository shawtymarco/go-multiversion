# Minecraft 1.21.10x wire audit

## Scope and authority

This adapter covers stable Minecraft 1.21.100, 1.21.101, and 1.21.102 under
protocol 827. Minecraft 1.21.110 starts protocol 844 and remains a separate
adapter. The target baseline is gophertunnel
`49e707e218caac5b1e37fc2fe11bb1727ab2b838`; the native model is
`7f058e5ddc393eaa0480dae338c5eee2feb323e6` at protocol 2169.

Two later gophertunnel corrections apply to packet layouts that did not change
between protocols 827 and 844: `5fe8be4677a1dd1033ae5befcc3ff798d224e571`
and `cb2317fb74c2fb90029ade5839e57add19680481`. The protocol-844-only
`PlayerArmourDamageEntry` hunk is excluded; protocol 827 retains its bitset and
conditional Varint32 damage fields. Mojang's `r/21_u10` protocol documentation
is pinned at `d7117467e8e5125bc10097c756cda93562273c0c`.

No patch-internal wire split was found among the three stable releases. One
adapter selects only the advertised StartGame version from the allow-list.

## Differences from protocol 844

- Protocol identity is 827 and `ServerBoundPackSettingChange` at packet ID 329
  is absent. The listener pool has 78 entries; the server pool exposes 210 of
  the historical 211 entries because `ServerScriptDebugDrawer` at ID 328 has
  no faithful current representation and collides with current
  `PrimitiveShapes`.
- `BiomeDefinition` carries red-spore, blue-spore, ash, and white-ash densities
  instead of `FoliageSnow`. The adapter restores the exact historical vanilla
  densities for Crimson Forest, Warped Forest, Soul Sand Valley, and Basalt
  Deltas. `BiomeClimate` carries the four density floats and
  `BiomeChunkGeneration` has no default-overworld-surface flag.
- `PlayerArmourDamage` uses a five-bit presence mask followed by one Varint32
  damage value per present slot. Invalid, duplicate, or non-int16-representable
  values are rejected rather than silently truncated.
- `LevelSoundEvent` ends at numeric event 562. The three protocol-844 swap/place
  events fall back to the historical default sound when sent from native.
- General game-rule integers remain Varuint32, including
  `GameRulesChanged`; StartGame also uses the legacy width.
- `UseItemActionUseAsAttack`, the extra entity-data flag, pack-setting types,
  and the protocol-844-only packet are not advertised as protocol-827 values.

All other protocol-844 adapter behavior that predates the family transition is
retained: historical packet IDs and layouts, unsigned-Y positions, inventory
and item-stack representations, commands, scoreboard splitting, StartGame,
resource packs, recipes, cache/status packets, and direct conversion to the
current native model. Inputs are cloned before mapping and unsupported packets
are dropped explicitly.

## Verification

The suite validates identity, exact pool sizes, all three allowed
GameVersions, input non-mutation, mixed packet splitting, the old armour mask,
all four biome ambience densities, and populated boundary fixtures. With
`V827_WIRE_ORACLE` pointing to the helper built from the locked target plus the
two documented protocol-agnostic corrections, every valid zero-value packet in
both pools and every populated/high-risk fixture decodes and byte-identically
re-encodes.
