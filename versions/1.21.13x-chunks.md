# Minecraft 1.21.130-1.21.132 chunk mapping

Protocol 898 uses the same version-9, expanded-height, 3D-biome chunk model as
the later protocol-924 family. Its exact block registry shares the same 15,845
states and FNV-1 ordering, so the generic pre-hash palette mapper produces
target bytes and cache hashes without mutating live chunks.

LevelChunk, SubChunk, cache blobs, ordinary and sub-chunk block updates,
falling-block metadata, and block-bearing inventory stacks all use the direct
native-to-898 mapping. Semantic anchors include stone 2532 and air 12530;
native-only states explicitly fall back to that verified air RID. Real-client
visual checks remain delegated to the server operator.
