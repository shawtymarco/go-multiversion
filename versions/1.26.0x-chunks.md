# Minecraft 1.26.0-1.26.3 chunk mapping

Protocol 924 uses the existing generic pre-hash `BlockRuntimeIDMapper` path.
World chunks are cloned per connection, every palette entry is mapped by full
identifier and typed states, fallback duplicates are compacted, and target
bytes are hashed only after conversion. LevelChunk cache-on/off, SubChunk,
cache-miss, block-update, falling-block, and inventory block IDs therefore
share one target registry.

The target keeps the modern world height, sub-chunk version 9, and 3D biome
palettes. No separate raw chunk layout is required; target air is RID 12530.
Real-client visual checks remain delegated to the server operator.
