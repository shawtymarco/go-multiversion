# Minecraft 1.26.60.29 native wire preparation

The `feat/26.60` branch uses native protocol 2223 from the published gophertunnel
fork `34adb6d`, which retains the stable fork's transport/session fixes and merges
upstream `28c02f0`. [The source lock](1.26.60-preview.29-native.yaml) records exact
commits. Stable `main` remains at `b58fcf5`; the earlier 2223-to-2193 experiment is
excluded from this branch and retained only under its recovery tag.

## Outgoing native and historical codecs

`protocols/v1_26_50` freezes the outgoing 2193 wire model. `V1_26_50()` exposes its
wire-only constructor; it is deliberately absent from the registry-aware catalogue
until its mapping is configured. Existing 1.26.50 data hashes and sources remain
locked in [1.26.5x.yaml](1.26.5x.yaml). No BDS data was regenerated or copied.

The 2169 adapter reuses only the 2193 wire masks that remain compatible. Older
adapters retain their own layouts and direct semantic mapping to native 2223:
there is no target-to-target semantic chain. This prevents new editor, passenger,
hand, biome-update, cloud and verified-account fields from leaking into older wire
layouts. Preview-only packet IDs 353-360 are excluded from all historical pools
and conversions.

The migration also updates:

- optional education capability objects and diagnostic categories;
- required 2193 diagnostic positions/dimensions to optional native fields;
- seven legacy sound updates to the native single effective update;
- shifted crafting action indices, using frozen historical constants;
- removed cosmetic skin PlayFab fields, using an empty historical value without
  promoting it to a verified account identity;
- environment constants/transitions/noise variants and former layer noise names;
- diagnostic category numeric tables using exact source names against native 2223.

The environment bridge omits preview-only clock names. For transition packets,
the legacy current-value slot uses the native starting value because the new model
does not carry a separate evaluated current value. Different per-attribute noise
names cannot be expressed by a single historical layer noise name. These cases
remain limits of this wire preparation and need policy/real-client validation
before enabling those features for historical clients.

## Validation and deferred integration

The independent `tools/oracle_native2193` module imports only the immutable outgoing
dependency. Its 17 synthetic packet fixtures are decoded/re-encoded against both
the frozen reference and the new historical adapter with no unread bytes. Additional
tests cover native input preservation, added-field exclusion, preview-only packets
across all 14 historical adapters and the shifted deprecated crafting actions.
Existing historical wire goldens remain in place. Skin fixtures now use the empty
cosmetic PlayFab field, which the native skin model cannot represent.

Regenerate the reference fixtures from the oracle directory:

```text
go run . > ../../protocols/v1_26_50/testdata/native2193.json
```

Native .29 block/item/creative/recipe/biome extraction and validation remain deferred
by request. Existing mapper tests use their frozen/synthetic native inputs; passing
them does not establish correctness with the actual .29 registry. Dragonfly, Spectrum,
BRBW pins/listeners and live servers are unchanged. Real-client login, chunks,
inventory, resource packs and transfers remain untested on this branch.
